# Deep Learning Computer Vision Digit Classifier

A Convolutional Neural Network (CNN) built in TensorFlow/Keras for multiclass image classification.

## Architecture
- Input: 28x28 grayscale images (MNIST dataset)
- Layers: Conv2D, MaxPooling2D, Dropout (regularization), Dense output (Softmax)
- Results: 98%+ validation/test accuracy with low generalization error.
